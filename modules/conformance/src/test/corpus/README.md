# The corpus

One directory per package the conformance tests build with the pinned `ridl`.
Each is copied unchanged from `driftsys/ridl` at the tag in
`../../../ridl-release`, except `kt-values` and `kt-foreign`, which are this
repository's own, as are `kt-zero`, `kt-unit`, `kt-podbuf` and `kt-proto3`, and
the `ridl.toml` of five single-file fixtures, which the ridl tests compile
without a manifest. Each `ridl.toml` names the encodings both backends generate:
FlatBuffers alone, except `kt-podbuf`, which selects podbuf alone, `kt-proto3`,
which selects proto3 alone (#133), and `cabin` and `kt-values`, which select
FlatBuffers and podbuf (#134).

`veh-common` references `ridl.std`, which `ridl build` writes as a package of
its own, so the plugin is also run on the standard library's patterned strings
and fixed-length bytes.

`kt-podbuf`'s float-keyed maps, `Tails.byGain` (f64) and `Tails.byRatio` (f32),
and `Narrowed.byLevel` (f32, the Rust fixture's), are sampled on distinct values
on the f32 grid. Two f64 keys that round to one f32 are one key: both encoders
refuse them with `Unique` (driftsys/ridl#1285), and the `PodbufEmitterRunTest`
probe covers that case. driftsys/ridl#1280's other case, an enum key of 2^63 or
more, has no source: a map key is a named string or a primitive (TYPL-209).
